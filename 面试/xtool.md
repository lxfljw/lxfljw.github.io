# 自我介绍

面试官好,我叫卢晓锋,有 8 年前端开发经验,近一年多在有赞做全栈开发。技术栈上,前端以 Vue、React 和工程化体系为主,同时具备 Java 后端能力。

在过去的工作中,除了业务开发,我更关注架构设计和研发效率。比如在兔展负责智慧零售 SaaS 平台时,我主导了 Vue 1 → Vue 3、Webpack 1.x → Webpack 5 的架构升级,重构了强耦合的核心装修模块,整体开发效率提升约 20%,本地构建速度提升约 90%;也牵头做过前端工程化基线建设,通过 CLI + 远程模板把项目初始化、监控、Lint、CI、埋点标准化,新项目启动效率提升约 90%。

到有赞之后,我发现很多研发效率问题不只是前端代码问题,而是涉及需求分析、系统设计、前后端协作和工程流程,所以开始往全栈方向发展。前端上主导了仓库从 Yarn 到 pnpm 的迁移和 Node 升级;后端上用 Java 落地了用户权益自动过期与标签增量刷新链路,通过窗口筛选、分批处理和聚合去重,用增量任务替代全量重算,降低了 DB 压力。

最近我比较关注 AI Native 的研发模式,并主导落地了团队内的 dev-flow MCP。我的理解是,AI 不只是代码补全工具,而是如何结合企业项目上下文、研发规范,通过 Agent、Workflow、MCP 把 AI 融入需求分析、问题排查、开发和代码 Review 的完整研发流程。在这个项目里,我把发布、日志查询、数据库查询、内部接口调用等原本要在浏览器手动操作的能力封装成 MCP Tool,并复用浏览器登录态实现无感鉴权,把排查和发布链路收敛到 IDE 内由 AI 助手按步骤完成,提升了团队研发协作效率。

重要： 需求输出技术文档，一定要review

个人在 java 方面，也开始吧目标定成，AI 写完的代码，自己也能去Review，平时也会做一些学习和实践，比如了解接口通过哪些手段扛住高并发，做一些SQL的慢查优化

整体来说,我希望能具备从业务需求到系统落地的完整能力
